🤖 AI Chatbot Android Application

An AI-powered Android application that allows users to interact with an intelligent chatbot and receive AI-generated responses. Developed using Kotlin and XML in Android Studio, the application integrates the Groq API to provide AI-powered conversations.

✨ Features

- 🤖 AI-generated responses using the Groq API
- 💬 Interactive chat interface
- ⌨️ Text-based messaging
- 🎙️ Voice input using speech recognition
- 🎨 Simple and user-friendly design
- 📱 Successfully run and tested on an Android device

🛠️ Technologies Used

- Kotlin: Application logic
- XML: User interface design
- Android Studio: Development environment
- Groq API: AI response generation
- Android SDK: Android application development

🚀 Installation and Setup

1. Clone this repository:
   git clone https://github.com/mahadebrana01/AI_Chatbot_Application.git
3. Open the project in Android Studio.
4. Wait for Gradle synchronization to complete.
5. Configure your Groq API key securely.
6. Connect an Android device or start an emulator.
7. Click Run ▶️ to build and launch the application.

🔑 API Configuration

This project uses the Groq API to generate chatbot responses.
1. Visit the "Groq Console" (https://console.groq.com/).
2. Create an API key.
3. Configure the key according to your application's implementation.
